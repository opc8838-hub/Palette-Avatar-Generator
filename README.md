# Palette Avatar Generator

[打开头像工作室](https://opc8838-hub.github.io/Palette-Avatar-Generator/)

首页可选择上传照片、使用照片样例或体验手绘样例。在浏览器中抠出人物，切换同色微染、中性黑白或保留原色，选择背景颜色，添加人像背后文字，并下载 256、512 或 1024 像素方形 PNG。颜色切换和手机开合互不影响。照片仅在当前浏览器处理，不会上传到服务器。

## 使用

编辑器新增「头像风格 → 简约手绘」，可以选已确认的男女样例，切换 Line / Solid / Color。Line 使用浅灰、白底、无妆色；Solid 可独立调整腮红和唇色；Color 额外支持背景与实际服饰配色，服饰可保持原色，头发和肤色保持原样。三个版本同步到四个社媒主页、折叠手机、动效和 PNG 下载。当前为两个手绘样例，上传照片自动转手绘尚未接入。

1. 使用默认人物，或上传 JPG、PNG、WebP、AVIF 照片。
2. 选择人像模式、调整构图和背景色。自动换色的播放速度可以调整。
3. 按需展开“头像背后文字”，输入自己的内容或选择示例文字，再调整字体、大小和位置。
4. 到“社媒对比”检查四个平台的模拟主页。
5. 到“保存头像”下载单张 PNG，或下载三版各三种尺寸的 ZIP 套装（共九张 PNG、配色记录和说明）。
6. 点击“保存草稿”显式保存当前人物与设置；下次从首页恢复。只保留最近一份草稿，更新会覆盖它；清除网站数据后无法恢复。草稿不会跨浏览器或设备同步。

照片套装为原色、黑白、微染；手绘套装为 Line、Solid、Color。当前编辑与导出免费体验，账户、自动转绘及付费生成尚未接入。

清晰的原始照片会得到更好的边缘效果。

右上角“关灯／开灯”切换工作室的黑白主题，页面文字和编辑控件同步适配，并记住上次选择。四台社媒手机保持各自原有的界面颜色。明暗以柔和渐变过渡，透明设备画布与页面共享同一层背景；开启系统“减少动态效果”后直接切换。

## 头像动效

底部“动效预览”使用当前头像、人像模式、构图和文字。可以拼成一张头像，或每个格子显示完整头像；配色支持统一使用当前背景色、当前系列随机以及整个色库随机。

右侧编辑器支持 3×3–13×13 格子、六种形状、十二种动效、速度、方向、起点、明暗/缩放和发光。点击“编辑格子”可点选或拖动绘制亮起范围，方向键与空格也可操作。可以暂停、重播、拖动进度，并导出 1200×1200 当前帧 PNG 或自带头像素材的离线动效 HTML。

格子编辑与动效类型参考 [Dot Motion Builder](https://github.com/LerSent001/dot-motion-builder) 的公开代码，头像合成、采样器、界面与导出在本项目中独立实现。动效素材按颜色缓存，播放帧直接更新 Canvas。

## 本地开发

```bash
npm ci
npm run dev
npm test
npm run build
```

`main` 分支更新后，GitHub Actions 会构建并发布到 GitHub Pages。页面使用本机 MediaPipe 人像分割，部署后不需要本地服务，也不依赖 Vercel。GitHub Pages 不提供动态图片生成接口，因此这一版按使用者选择暂不显示 AI 抠图按钮。

## 技术结构

React 负责编辑器，Three.js 负责折叠设备预览。`app/avatar-engine.js` 在本机分离人物、合成头像并导出 PNG；`app/motion-controller.js` 独立处理手机动作。设备模型和材质基于 [iPhone Duo motion study](https://github.com/bravohenry/iphone-duo-motion-study) 改造。

文字编辑的字体选择参考了 [CellMotion 图标爆发](https://github.com/opc8838-hub/font-animation/tree/main/site)；所用字体及其 OFL 许可文件一起保存在 `assets/fonts/`。
